AshPoint Chat 1.0.0 adds server-only private messaging, persistent mutes/ignores and preferences, SocialSpy, staff chat, slow/locked chat, configurable anti-spam and mentions, clear chat, and target-permission sudo.

Target: Minecraft 26.3, Java 25, Fabric API 0.161.0+26.3. No client mod. LuckPerms 5.5.x optional; tested with 5.5.85 and matching Carpet 26.3.

Install only ashpoint-chat-1.0.0.jar in your server mods folder. Formatting is off by default. Reload configuration with /ashpointchat reload.

Sudo chat uses unsigned player chat; it cannot create a connected player's signature. Clear chat pushes history out of view with blank lines. Read README.md for command ownership, permissions, configuration and these vanilla-client limits.
